# big_k-modern_1

  ＜빅데이터로 읽는 한국근대사 1＞ 교과목 코드입니다.
  아래 **A~E 다섯 단계**를 한 번만 해 두면 학기 내내 씁니다.

  > **회색 상자 오른쪽 위의 복사 아이콘**을 누르면 그대로
  복사됩니다. 손으로 치면 오타가 납니다.

  ---

  ## A. 코랩 설치

  1. 구글드라이브에서 **[+ 신규] → 더보기** → 맨 아래 **연결할 앱
  더보기**
  2. 검색창에 `colab` → **Colaboratory** → **설치**

  ⚠️  「설치 중」이 계속 도는 것처럼 보이면 **창을 닫고 드라이브를
  새로고침**하십시오. 이미 깔려 있습니다.

  ## B. 작업 폴더 만들기

  "내 드라이브"에 아래 이름으로 폴더를 만듭니다.

  ```
  big_km_history01
  ```

  그 폴더 **안에** 하위 폴더 둘을 만듭니다.

  ```
  data
  ```

  ```
  result
  ```

  🔴 **셋 다 소문자입니다.** 대문자로 만들면 코드가 폴더를 찾지
  못합니다.

  ## C. 코드 파일 가져오기

  1. 이 저장소에서 해당 `.ipynb` 파일을 누릅니다 (미리보기 상태로
  열립니다)
  2. 왼쪽 위 **Open in Colab**
  3. 🔴 **파일 → Drive에 사본 저장** ← **이걸 해야 내 것이 
  됩니다.** 안 하면 실행되지 않습니다
  4. 파일 이름에서 **"의 사본"**을 지웁니다
  5. 이 파일은 **"내 드라이브 / Colab Notebooks"**에 있습니다 →
  마우스 우클릭 **정리 / 이동** → `big_km_history01` 로 옮깁니다

  옮기고 나면 이런 모양이 됩니다. **이 구조를 지켜야 코드가 
  폴더를 찾습니다.**

  ```
  big_km_history01
  ├─ 02_1_코랩파이썬.ipynb
  ├─ data
  └─ result
  ```

  ## D. 구글드라이브 연결하기 (드라이브 마운트)

  1. 코랩 왼쪽 세로 막대의 **폴더 아이콘**을 누릅니다
  2. **드라이브 마운트** → **구글 드라이브에 연결** → 계정 선택 →
  승인
  3. 왼쪽에 `drive/MyDrive/big_km_history01/` 이 보이면 **된 
  것입니다**

  🔴 **폴더를 만든 그 계정으로 승인**하십시오. 계정이 여러 개면
  여기서 엇갈립니다.
  🔴 **연결하지 않으면** 저장한 파일이 코랩 임시 공간에 들어가,
  **코랩을 닫는 순간 사라집니다.**

  ## E. 되는지 확인

  1. 노트북을 위에서부터 실행하면 **표가 하나 뜹니다**
  2. `result` 에 저장한 파일이 **내 드라이브에서 보이면 
  끝**입니다

  ---

  ## 분석 데이터 넣기 — **4주차에 합니다**

  이 저장소 `data` 폴더의 파일을 내려받아 `big_km_history01/data`
  에 올립니다.
  **2주차에는 하지 않습니다.** `data` 폴더는 비워 둔 채로
  두십시오.
