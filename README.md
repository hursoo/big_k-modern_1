# big_k-modern_1
<빅데이터로 읽는 한국근대사 1> 교과목 관련 코드입니다.

---

## 1. 구글드라이브 폴더 경로 지정
- 구글드라이브의 "내 드라이브"에 다음과 같이 폴더를 만듭니다.
- **big_km_history01**
    - **data**
    - **result**

## 2. 파일 내려받기
### 2.1. 파일 내려받아 구글드라이브 폴더에 저장하기 : 데이터 파일
- 깃허브의 '**data**' 폴더에 있는 파일을 자신의 로컬 컴퓨터에 다운로드합니다.
- 이 파일을 다시 "**big_km_history01/data**" 에 업로드합니다.

### 2.2. 파일 내려받아 구글드라이브 폴더에 저장하기 : 파이썬 코드 파일(.ipynb)
- 깃허브의 해당 파일을 마우스 좌클릭하면 해당 파일이 열립니다.(preview 상태)
- 왼쪽 상단의 "**Open in Colab**"을 마우스 클릭합니다.
- 그러면 이 코드 파일이 열립니다.
- 이 코드 파일을 사용하려면, 팝업메뉴 "**파일/Drive에 사본 저장**"을 클릭합니다.
- 그러면 이 코드 파일 이름이 "**(본래 이름)의 사본**"으로 변경됩니다. 이 파일의 위치는 "**내 드라이브/Colab Notebooks**"에 있습니다.
