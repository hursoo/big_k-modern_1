A코랩 설치

  1. 드라이브 [+ 신규] → 더보기 → 맨 아래 연결할 앱 더보기
  2. colab 검색 → Colaboratory → 설치
  3. 「설치 중」이 계속 돌면 창을 닫고 새로고침 — 이미 깔려 있습니다

B폴더 만들기

  1. 내 드라이브에 새 폴더 big_km_history01
  2. 그 안에 data
  3. 그 안에 result  모두 소문자

C코드 파일

  1. GitHub에서 02_1_코랩파이썬.ipynb
  2. 왼쪽 위 Open in Colab
  3. 파일 → 드라이브에 사본 저장 — 안 하면 실행이 안 됩니다
  4. 이름에서 「의 사본」 지우기
  5. Colab Notebooks에 있습니다 → 우클릭 정리 → 이동 → 작업 폴더로

D드라이브 연결

  1. 코랩 왼쪽 폴더 아이콘 → 드라이브 마운트
  2. 연결 → 계정 선택 → 승인  폴더를 만든 계정으로
  3. 왼쪽에 drive/MyDrive/big_km_history01/ 이 보이면 됩니다

E확인

  1. 노트북을 위에서부터 실행 → 표가 뜹니다
  2. result 에 저장한 파일이 드라이브에 보이면 끝
